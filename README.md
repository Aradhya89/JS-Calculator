# JavaScript Calculator

A responsive calculator built using **HTML, CSS, and JavaScript**, featuring keyboard support, basic arithmetic operations, and expression handling.

## Live Demo

🔗 [View Calculator](http://aradhya.lusa.co.in/JS-Calculator/)

## Features

- Basic arithmetic operations (+, -, *, /)
- Keyboard support for entering expressions
- `Enter` to calculate the result
- `Backspace` to delete the last character
- `Ctrl + Backspace` to clear the expression
- Error handling for invalid expressions
- Responsive UI using CSS Grid

Calculator/

## Technologies Used

- HTML5
- CSS3 (Grid & Flexbox)
- JavaScript (DOM Manipulation & Event Listeners)

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Aradhya89/JS-Calculator.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
